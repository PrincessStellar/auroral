# Auroral 1.5.4

## Added

- **The Auroral Guidebook** is now its own Auroral item with a proper recipe and a real icon. Crafting a book with a snowball still produces the guidebook, and right-clicking it opens the Auroral guide.

## Changed

- **The in-game guide has been completely restyled.** Every page now opens with a large item picture and a one line summary, sections are separated by clear dividers, and headings are colored. Important sub-topics show a small inline item picture next to a colored sub-heading. Recipes appear inline beneath the relevant block, and cross-references between pages are clickable item links.

## Fixed

- **The guidebook now registers as a proper Auroral item.** Previously the recipe produced a generic GuideME book that carried the Auroral guide reference internally, which meant it never appeared as an Auroral item to JEI lookups, search, KubeJS scripts, or `/give` commands. The new guidebook is a real Auroral item that behaves the same as any other.
- **The guide table of contents now lists every page under the Auroral heading**, each with the correct icon next to its entry. Before this fix, only the home page and a couple of others were attached to the main heading. The rest of the pages floated around the table of contents without parents or icons.
- **Guide page files have been relocated** to the folder GuideME expects, which prevents the guide from failing to load when other mods that use GuideME are installed alongside Auroral.
- **The Food and Drinks heading in the guide** no longer shows the literal text `&amp;` instead of an ampersand.

## Docs

- Every guide page now has a hero picture at the top, gold colored section headings, and inline cross-links and recipes where relevant. This covers the Introduction, First Steps, Aurora Events, Aurora Creatures, all Flora pages, every Shimmersteel and Shimmerweave gear page, Decorations, and Food and Drinks.
- Page ordering in the table of contents now follows category ranges, so the list reads top to bottom in the same order as the home page: Getting Started, the Aurora, Flora, Shimmersteel, Shimmerweave, Decorations, then Food and Drinks.
