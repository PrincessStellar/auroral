# Auroral 1.3.1

## Added

- Tamed Auroral Nautili within 32 blocks of you when you change dimensions (nether portal, end portal, `/tp`, etc.) now follow you to the destination
- Aurora Blooms placed on a snow layer now visually keep a snow base around them (rendered via a multipart blockstate), so snow-logged blooms read as snow-logged at a glance

## Fixed

- Aurora Blooms placed on a snow layer now replace the layer at the same Y level and remember the snow context (snow-logged), instead of being placed floating above the layer (1.3.0 regression)
- Aurora Blooms can now be planted on snow layers with 2+ layers — vanilla only marks 1-layer snow as replaceable, so multi-layer snow used to push the bloom into the block above. The bloom item now overrides this so it always replaces at the same level
