# Auroral 1.3.0

## Added

- Aurora Blooms can now grow on Ice, Packed Ice, and Blue Ice in addition to snow and Shimmering Ice (so frozen ocean surfaces are now valid spawn ground)
- Aurora Blooms placed on a snow layer or in powder snow (manually or by the mod) are now **snow-logged**: the bloom replaces the snow at the same level and remembers the original snow type. When the bloom is broken or wilts, the matching snow (snow layer or powder snow) is restored
- Tamed Auroral Nautili within 32 blocks of you when you change dimensions (nether portal, end portal, /tp, etc.) now follow you to the destination dimension
- Glacial Basin output slot can now be emptied by sneak + right-clicking the basin with an empty hand
- Glacial Basin extraction via automation is restricted to the output slot — pipes can no longer pull queued items out of the input slot
- Snow-logged blooms emit faint snowflake particles above themselves so they can still be located when buried under additional snow
- Snow Angels are now tagged as replaceable, so blocks can be placed directly into a snow angel's space without breaking it first

## Fixed

- Aurora Blooms can no longer be spawned on a snow layer whose underlying block isn't a valid bloom surface, preventing blooms from being left sitting on stone or dirt after the snow melts
- Aurora Bloom natural spawning now fires a block-place event, so claim-protection mods like FTB Chunks can prevent blooms from appearing inside other players' claimed chunks
- Aurora Bloom surface scanning now picks the topmost snow/ice in a column, so snow layers sitting on top of snow blocks are recognized as the spawn target rather than blocking the place-above branch
- Snow Angels now require **both** hands to be empty to be created, rather than only the main hand

## Tweaks

- When a snow-logged Aurora Bloom dies (daytime wilt or surface lost), it now decays back into the snow it was logged with (snow layer or powder snow) instead of vanishing
