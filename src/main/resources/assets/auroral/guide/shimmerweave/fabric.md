# Shimmerweave Fabric

Shimmerweave Fabric is a magical cloth infused with aurora energy. Light yet durable, it's used to create the Shimmerweave armor set.

## Obtaining Shimmerweave Fabric

### Glacial Basin Infusion

Infuse Leather or Wool in a [Glacial Basin](../shimmersteel/glacial_basin.md) filled with Liquid Aura:

1. Place a Glacial Basin under open sky
2. Wait for an [Aurora Event](../aurora/aurora_events.md)
3. Right-click the basin with Leather or any color Wool
4. Receive Shimmerweave Fabric!

## Properties

- **Lightweight** - Armor made from Shimmerweave has minimal weight
- **Aurora Affinity** - Armor repairs itself during aurora events
- **Magical Conductivity** - Enables special abilities in each armor piece

## Uses

Shimmerweave Fabric is used to upgrade iron armor via the Smithing Table:

- <ItemImage id="shimmerweave_goggles" scale="0.75" /> [Shimmerweave Goggles](goggles.md) - Reveals hidden enemies
- <ItemImage id="shimmerweave_tunic" scale="0.75" /> [Shimmerweave Tunic](tunic.md) - Fire protection
- <ItemImage id="shimmerweave_leggings" scale="0.75" /> [Shimmerweave Leggings](leggings.md) - Speed on snow
- <ItemImage id="shimmerweave_skates" scale="0.75" /> [Shimmerweave Skates](skates.md) - Master of ice

You'll need a **Shimmersteel Upgrade Smithing Template** to perform these upgrades.
